# elisaarmas.com — custom WordPress code

Custom theme and plugin code for [elisaarmas.com](https://elisaarmas.com/). The layout mirrors `wp-content/`:

| Path | Description |
|------|-------------|
| `themes/elisa-dela-cruz/` | Active theme |
| `themes/elisaarmas-2026/` | Theme (in development) |
| `plugins/elisaarmas-visitor-log/` | Visitor log / blocker plugin |

WordPress core, third-party plugins/themes, uploads, and `wp-config.php` are intentionally not included.
